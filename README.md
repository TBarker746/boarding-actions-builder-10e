Warhammer 40,000 10th Edition: Boarding Actions
==================

## Overview ##

This repository is an in-progress adaptation of the BSData team's 40K Army Builder specifically to handle the Boarding Actions game mode, which I resurrected and completed in the dying days of 10th Edition after the BSData team pivoted to preparing for 11th Edition, leaving the 10th Edition Boarding Actions ruleset incomplete; as Boarding Actions appears to be receiving no rules support at all in 11th, this is now the place to come if you want a builder for the most up-to-date version of the ruleset available!

This dataset has been written for the list-building application New Recruit, and can be implemented into it by clicking the "Add more games" button while on the My Games Page and selecting "Add from Github".

As this repository is an adaptation of another project, if you want to submit a  [bug report][bug report], please check out the [notes page](https://github.com/TBarker746/boarding-actions-BSdata-draft/blob/main/BUGNOTES.md) first, as certain issues should probably be reported on the [original dataset](https://github.com/BSData/wh40k-10e/blob/main/README.md) rather than here. **Please note that the 10th Dataset is no longer actively receiving support and thus bugs there are unlikely to be addressed (although we may then fix those issues in 11th Edition if they are also present there) - I, however, will see them as I'm a contributor on that repo too now, and will be able to port relevant fixes over to here.**

[bug report]: https://github.com/TBarker746/boarding-actions-builder-10e/issues/new/choose
